처음 한 번 사용할 요청문

기존 지침과 README를 먼저 확인하고 이 툴킷의 AGENTS 예시에서 필요한 규칙만
현재 프로젝트 지침에 합쳐줘. 원래 규칙과 제출 요구를 덮어쓰지 마.
반복 규칙은 AGENTS.md, 현재 요구·상태·검증은 WORKLOG.md에 유지해줘.

180분 안에 필수 결과를 완성하고 내가 구조·검증·한계를 설명할 수 있게 진행하자.
README에 이미 명확한 것은 다시 장시간 인터뷰하지 말고, 구현을 바꿀 모호함만 질문해줘.
기존 스택과 실행 명령을 활용하고, 합의된 범위의 구현·검증은 불필요한 재승인 없이 이어가줘.

독립 작업은 계약과 파일 소유권을 정한 뒤 병렬로 진행해줘. 처음에는 쓰기 작업자
2개 이내로 시작하고, 완료된 결과부터 검토·통합하며 다음 실행 가능한 작업을 진행해줘.
워크트리가 필요하면 허용된 작업 공간 안에서만 사용하고, 실제 지원 여부와 설정 비용을 확인해줘.
격리가 불가능하거나 비용이 크면 한 명 구현·다른 역할 읽기 전용 검토로 진행해줘.

60분 안에 핵심 경로를 한 번 연결하는 것을 목표로 하고, 150분 전후부터는
새 작업보다 통합·결함 수정·설명에 집중하자. 중요한 선택과 변경은 이유·위치·검증·한계를
짧게 설명해줘. 전역 설정·제공 도구 버전·감독 기능은 바꾸지 말고 외부 전송은 하지 마.

이후 요청은 바뀐 내용만 전달
예: T2 진행해줘. 계약 v1 유지. 수정 범위는 작업판대로. 남은 시간 95분.
예: T1 결과를 먼저 통합하고 관련 검증을 실행해줘. T2는 계속 진행.
예: WORKLOG에 현재 코드 상태와 다음 명령을 남겨줘. 새 세션에서 이어갈게.
