## Cofa Helper에 확인할 것

- 체험 파일·설정·세션의 본시험 유지 여부: 미확인
- 제출 대상 루트와 별도 worktree 결과의 포함 방법: 미확인
- 환경 기록의 허용된 보존·반입 방법: 미확인
- 답변 또는 최신 안내의 근거·시각: 미확인

## 본시험에서 다시 확인할 것

- 실제 README의 목표·필수 산출물·변경 금지 범위
- 실제 루트·스택·실행/테스트 명령·최종 제출 경로
- 재설치 없이 쓸 수 있는 toolkit과 Codex 지침 적용 여부
- 병렬 전략: 확인되면 최대 2개부터 / 아니면 한 명 구현과 읽기 전용 검토
- 30~60초 이상 막힌 선택 기능은 기록 후 생략하되, 기본 실행·감독 장애는 우선 대응

## AGENTS.md에 옮길 확인된 반복 규칙

아래의 대괄호를 실제 확인값으로 바꾼 항목만 기존 지침에 합친다.
확인되지 않은 항목은 규칙으로 단정하지 않는다.

- 기존 과제 지침과 README를 우선한다. 작업 루트는 [경로], 최종 제출 경로는 [경로]다.
- 실제 과제 실행은 [명령], 검증은 [명령]을 사용한다.
- 미리보기 서버는 0.0.0.0에 바인딩하고 출력된 실제 포트와 경로를 플랫폼 Browser에 넣는다.
- 병렬 작업은 [확인된 방식]으로 [확인된 한도] 내에서 진행하며, 불가하면 [대안]을 쓴다.
- 별도 작업 공간의 결과는 [제출 루트]로 통합하고 그 상태에서 검증한다.
- 준비 자료는 [허용된 공개 저장소와 커밋]에서 [경로]로 가져온다.
- 제공 도구 버전·승인 정책·감독 설정을 임의로 바꾸지 않는다.

Codex 지침 자동 발견은 새 세션에서 확인한다. 현재 세션에 파일을 읽으라고
명시한 경우는 자동 발견과 구분한다. 전체 관찰표를 AGENTS.md에 복사할 필요는 없다.
