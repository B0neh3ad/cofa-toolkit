# 3분 Browser 연습: 작업 환경 체크리스트

서버 실행 → 플랫폼 Browser 연결 → 입력·버튼 → 새로고침을 확인하는 완성된 작은 앱입니다.
의도적인 결함을 고치는 기존 주문 CSV 과제와 별개입니다. Python 3와 브라우저만 사용하며,
패키지 설치·API 키·외부 서비스·빌드가 필요하지 않습니다.

## 1. 실행 — 약 30초

**cofa-toolkit 루트에서** 다음 명령을 실행합니다.

```sh
python3 -m http.server 3000 --bind 0.0.0.0 --directory practice/browser
```

서버가 실행 중인 터미널은 유지합니다. Codex나 다른 명령은 새 터미널에서 사용하세요.
위 명령은 연습 폴더만 서비스합니다. 과제 전체나 비밀 파일이 있는 폴더를 서비스하지 않습니다.

- Cofa: 플랫폼 **Browser**에서 포트 `3000`, 경로 `/`를 입력하고 새로고침합니다.
- 개인 준비 환경: 브라우저에서 `http://localhost:3000/`을 엽니다.
- `Address already in use`라면 명령의 포트를 `3001`로 바꾸고 Browser에도 같은 값을 넣습니다.
- 연결 실패 시 **서버 오류·종료 → 실제 포트 → 0.0.0.0 → 경로** 순으로 확인합니다.
- 종료하려면 해당 서버 터미널에서 `Ctrl+C`를 누릅니다.

## 2. 직접 확인 — 약 2분

- [ ] `BROWSER PRACTICE · v1`과 처음 두 항목이 보인다. 이전 연습 기록이 있으면 `연습 초기화`를 누른다.
- [ ] 빈 입력 또는 공백만 넣고 `추가`를 누르면 오류가 보이고 개수는 늘지 않는다.
- [ ] `미리보기 성공`을 입력하고 `추가`를 누르면 전체가 3개가 된다.
- [ ] `Enter 확인`을 입력하고 Enter를 누르면 전체가 4개가 된다.
- [ ] 새 항목 하나를 체크하면 완료 1개·남음 3개가 된다. 다시 누르면 완료가 해제된다.
- [ ] 항목 옆 `삭제`를 누르면 해당 항목과 집계가 함께 바뀐다.
- [ ] 페이지를 새로고침하면 추가·완료·삭제 결과가 유지된다.
- [ ] `연습 초기화`를 누르면 초기 두 항목과 완료 0개로 돌아간다.
- [ ] 서버를 실행한 채 새 터미널에서 다른 명령을 사용할 수 있다.

화면이 떠도 버튼이 동작하지 않으면 JavaScript 실행 여부를 별도로 확인합니다.
브라우저 저장이 차단되면 경고가 표시됩니다. 이때 현재 창의 조작과 새로고침 후 보존을
구분해서 기록하세요. 다른 포트·호스트·브라우저에서는 저장 항목이 공유되지 않을 수 있습니다.
초기화는 이 앱의 저장 키만 덮어쓰며 다른 사이트나 앱의 저장소를 지우지 않습니다.

## 3. 환경 기록 — 약 30초

`templates/ENVIRONMENT.md`에 다음을 옮깁니다. 실제 확인하지 않은 것은 `미확인`으로 둡니다.

```text
실행 위치: 실제 경로
실행 명령: python3 -m http.server 실제포트 --bind 0.0.0.0 --directory practice/browser
Browser: 실제포트 / 실제경로
화면 표시: 성공 / 오류 / 미확인
추가·Enter·완료·삭제: 각각 성공 / 오류 / 미확인
새로고침 후 보존: 성공 / 차단·오류 / 미확인
서버 유지 + 별도 터미널: 성공 / 오류 / 미확인
```

## Codex에 줄 짧은 요청

```text
practice/browser/README.md를 읽고 기존 코드는 수정하지 않은 채 서버를 실행해줘.
작업 위치를 확인하고 연습 폴더만 서비스해줘. 0.0.0.0과 실제 포트로 띄우고,
실행 명령과 서버 응답 확인 결과를 알려줘. 설치나 업데이트는 하지 마.
플랫폼 Browser 연결과 버튼 조작은 내가 직접 확인할게.
```

터미널의 HTTP 응답 확인만으로 화면·버튼·저장소까지 검증했다고 보고하면 안 됩니다.
실제 Cofa 환경에서는 참가자가 플랫폼 Browser를 직접 조작하고 해당 시험 규칙을 따릅니다.

## 여유가 있을 때: AI 수정·저장 연습

Codex에게 **미완료 항목만 보기** 체크박스를 추가하도록 요청해보세요. 집계는 전체 항목
기준을 유지하고 기존 저장 형식과 추가·완료·삭제 동작을 보존하도록 요구합니다.
수정 후 에디터의 외부 변경 반영과 저장 상태를 확인하고 같은 체크리스트로 다시 검증합니다.
15분 사전 체험에서는 기본 실행·연결 확인을 먼저 마친 뒤 시간이 남을 때만 진행하세요.

## 준비 환경 검증

2026-10-30 로컬 Python 서버와 Chrome에서 HTTP 응답, 공백 거절, 버튼·Enter 추가,
완료 전환, 삭제, 새로고침 후 보존, 빈 목록 보존, 초기화를 확인했습니다.
HTML 형태의 입력이 실행되지 않고 문자로 표시되는지, 좁은 화면에서 가로 넘침이 없는지,
저장 데이터 손상 시 복구와 저장 차단 시 경고가 동작하는지도 확인했습니다.
해당 실행에서 페이지의 외부 요청과 처리되지 않은 JavaScript 오류는 없었습니다.
이 기록은 Cofa 플랫폼에서의 연결·감독·실행 성공을 증명하지 않습니다.
