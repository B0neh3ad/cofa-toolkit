툴킷 v4 검증 기록 — 2026-10-31

범위: 로컬 준비 환경, Python 3.12.14와 Node 24.15.0.
Cofa 플랫폼에서의 설치·연결·모델 행동·채점 결과는 검증하지 않았다.

1. 코드 회귀 검증
- 기존 실행 근거·제한된 비밀값 검사 도구: tests/test_tools.py 16개 통과.
- 선택형 설치·기존 지침 보존·경로/링크 경계·MCP 설정: tests/test_setup.py 9개 통과.
- 실제 CLI로 32개 Skill을 새 임시 프로젝트에 복사하고 기존 AGENTS를 보존했다.
- WORKLOG 복사와 JSON/TOML MCP 설정 생성·구문 해석을 확인했다.
- 설치와 검증 과정에서 사용자 전역 Codex 설정·Skill·모델·도구 버전을 바꾸지 않았다.

2. Skill과 출처
- Skill 32개의 frontmatter 형식을 검사했다.
- 외부 Skill 26개와 지원 파일, Spec Kit 원본 템플릿 5개를 가져왔다.
- 원본 커밋·경로·변경 내역·파일 SHA-256을 vendor/manifest.json에 기록했다.
- Skill·참고 문서의 로컬 Markdown 링크를 점검하고 빠진 agent 자료와 경로를 보완했다.
- property-based-testing의 effort를 metadata로 옮겨 형식 호환성을 보완했다.
- 형식·경로 검사는 실제 모델의 판단·실행 품질을 보증하지 않는다.
- 모든 외부 Skill의 전체 워크플로우·외부 의존성을 실행한 것은 아니다.
- 자체 작성 파일의 Git 공백 검사는 통과했다. 외부 원본 문서의 Markdown 줄바꿈·공백은
  보존했으므로 전체 git diff --check에는 해당 원본의 trailing whitespace 경고가 남는다.

3. MCP 런타임 검증 — 임시 데이터와 기존 legacy initialize 프로토콜
- filesystem: 시작·도구 목록·파일 읽기·허용 폴더 밖 접근 거절 통과.
- memory: 시작·도구 목록·entity 생성·검색·지정 파일 저장 통과.
- sequential-thinking: 시작·도구 목록·간단한 도구 호출 통과.
- dbhub: 시작·도구 목록·SQLite SELECT·INSERT 거절·원본 행 수 유지 통과.
- context7: 시작과 도구 목록 통과. 외부 문서 질의와 결과 품질은 미검증.
- openai-docs: 공개 HTTP 서버 initialize 응답 확인. 문서 검색/조회는 미검증.
- 로컬 패키지 5개는 고정 버전·전이 의존성 lockfile로 설치했다.
- node_modules는 공개 커밋과 ZIP에 넣지 않는다. 플랫폼에서는 선택한 패키지를 내려받아야 한다.

4. 공개용 정리
- practice 전체, CSV 전용 연습 Skill, worktree 실습 코드와 연습 문서를 제거했다.
- 원본 PDF·메일·개인 접속 링크·실제 과제 자료는 포함하지 않았다.
- 공개 대상의 제한된 자격증명 패턴 검사: 발견 0. 비밀정보 부재를 보증하지는 않는다.
- 기존 설정을 보존하는 설치와 MCP 미사용/미호환 시 대안을 문서화했다.

시험에서는 선택한 구성만 실제 환경에서 확인한다. 연결 성공, 도구 호출 성공,
실제 문제의 해결·검증 성공은 서로 다른 근거다.
